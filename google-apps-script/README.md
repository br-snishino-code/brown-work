# スプレッドシート用のスクリプト

## shift-import.gs — シフト希望の取り込み

Brown Work に提出されたシフト希望を、スタッフシフトのスプレッドシートへ取り込みます。

### 準備（初回のみ）

1. Supabase に合言葉を設定する

   ```
   supabase secrets set SHIFT_EXPORT_KEY=<好きな長い文字列>
   supabase functions deploy shift-requests-export --no-verify-jwt
   ```

2. スプレッドシートを開き、「拡張機能」→「Apps Script」
3. `Code.gs` の中身を消し、`shift-import.gs` の内容を貼り付けて保存
4. 「プロジェクトの設定」→「スクリプト プロパティ」に2つ追加

   | 名前 | 値 |
   |---|---|
   | `SUPABASE_URL` | `https://xxxxxxxx.supabase.co` |
   | `SHIFT_API_KEY` | 手順1で決めた合言葉 |

5. スプレッドシートを再読み込みすると「Brown Work」メニューが出ます

### 使い方

- 「Brown Work」→「シフト希望を取り込む」→ 対象月を入力
- 「シフト希望_2026-11」というシートに、スタッフ×日付の表が書き込まれます
- 「自動取り込みの間隔を選ぶ」で、毎朝1回（6時台）・30分おき・15分おき・5分おき から選べます
- 「自動取り込みの状態を見る」で、今の間隔と最後に動いた時刻を確認できます
- 「自動取り込みを解除」で止まります

### 自動取り込みの動き

- 前回と内容が同じときはシートを書き換えません。短い間隔にしても、見ている最中に表示が消えません
- 手動の「シフト希望を取り込む」は、変化がなくても必ず書き直します
- Google の時間指定は「その時間ちょうど」ではなく、その時間帯のどこかで動きます
- 受付期間中だけ短い間隔にして、締め切ったら「毎朝1回」に戻す使い方がおすすめです

### 確定シフトを Brown Work へ送る

スプレッドシートで組んだシフト表を、Brown Work に反映します。

- 「Brown Work」→「確定シフトを送る」
- 読み取る内容を確認する画面が出るので、問題なければ OK
- 自動取り込みを設定していれば、同じ間隔で自動でも送られます（内容が変わったときだけ）

#### 読み取り方

- 見出し行は「1(日)」のような日付が20個以上並んだ行を自動で探します
- 氏名の列は、見出しが「スタッフ名」「氏名」「名前」などの列を優先して探します。見つからないときは、日付より左でフルネームらしい値が多い列を選びます
- 1枚のシートに店舗ごとの表とスタッフごとの表が並んでいる場合も、氏名の列が空の行は読み飛ばします
- 自動で合わないときは「確定シフトの読み取り設定」でシート名と氏名の列（例：E）を指定してください
- 対象月はファイル名（例：2026年11月スタッフ勤務シフト）から読み取ります。読み取れないときは入力を求めます
- シートは「〇月」という名前のタブを自動で探します。違う名前のときは「確定シフトのシート名を指定」で設定してください

#### セルの中身

| セル | 扱い |
|---|---|
| 空欄 | 休み |
| 有給（×有給 など） | 有給 |
| それ以外（店舗名など） | 出勤。その文字が活動場所になります |

#### 氏名の突き合わせ

Brown Work の登録氏名との完全一致です（前後の空白と全角空白は自動でそろえます）。一致しなかった氏名は送信後の画面に出るので、どちらかの表記を直してください。

### 注意

- 合言葉を知っている人は、その月のシフト希望を読み取れます。スプレッドシートの共有範囲にご注意ください
- 書き込み先は専用のシートです。既存のシフト表は書き換えません
